# E-Commerce-Customer-Churn-Analysis

📌 Project Overview
Customer churn is a critical challenge in the e-commerce industry, directly impacting revenue and customer lifetime value. This project focuses on analyzing customer behavior and identifying key factors contributing to churn.

The analysis was performed using MySQL for data exploration and transformation, followed by Tableau for visualization, insights, and actionable strategies.

🎯 Objectives
- Identify patterns and trends behind customer churn
- Segment customers based on risk levels (High, Medium, Low)
- Analyze behavioral and demographic factors influencing churn
- Provide actionable recommendations to improve retention

🗂️ Dataset Description
The dataset consists of three interconnected tables, representing different aspects of customer data:
- Customer Profile Table
- Customer ID
- Gender
- Tenure
- Location / Address details
- Customer Behavior Table
- Preferred Login Device
- Preferred Payment Mode
- Order Count
- Activity-related features
- Transaction / Churn Table
- Cashback / Offers
- Churn Status (Retained / Churned)
  
🧩 Data Modeling
- Designed an Entity Relationship (ER) Diagram to understand relationships between tables
- Established primary and foreign keys for accurate joins
- Ensured data consistency and normalization before analysis

🛠️ Tools & Technologies
MySQL – Data cleaning, transformation, and analysis
Tableau – Dashboard creation and storytelling
ER Modeling – Database structure design

🔍 Data Analysis (MySQL)
Performed exploratory data analysis using SQL:
- Data cleaning (handling nulls, inconsistencies)
- Feature transformation (standardizing categories)
- Joins across multiple tables
- Aggregations and grouping for churn insights

📊 Tableau Dashboard
Developed an interactive dashboard with:
- Customer segmentation (Churn vs Retained)
- Demographic analysis (Gender, Tenure)
- Behavioral insights (Login Device, Payment Mode)
- KPI metrics (Churn Rate, Retention Rate)
  
💡 Key Insights
- Customers with low tenure show higher churn probability
- Certain payment modes are associated with increased churn
- Low engagement users (fewer orders/logins) are at higher risk
- Specific customer segments require targeted retention strategies

🚀 Action Plan
🔴 High-Risk Customers
- Implement targeted retention campaigns
- Offer personalized discounts and incentives
- Improve onboarding experience
🟡 Medium-to-Low Risk Customers
- Increase engagement through offers and recommendations
- Encourage repeat purchases with loyalty programs
- Maintain engagement to maximize lifetime value

📈 Outcome
This project provides a data-driven approach to reduce churn, helping businesses:
- Improve customer retention
- Increase revenue
- Enhance customer experience
